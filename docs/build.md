# Building

## Toolchain bootstrap (one time)

The SDK and LLVM 18 are **not** committed (1.7 GB). Install them into
`sdk/` with:

```sh
scripts/bootstrap_sdk.sh
```

The script is idempotent and installs:

- `sdk/ps5-payload-sdk` — [ps5-payload-dev/sdk](https://github.com/ps5-payload-dev/sdk)
  v0.44 (release zip);
- `sdk/llvm18/llvm@18/18.1.8` — Homebrew `llvm@18` bottle (arm64,
  pinned sha256), with install names patched to `/opt/homebrew` and
  **ad-hoc re-signed** (required on arm64 macOS — an invalidated code
  signature makes dyld hang on load).

Then build:

```sh
export PS5_PAYLOAD_SDK=$PWD/sdk/ps5-payload-sdk
export LLVM_CONFIG=$PWD/sdk/llvm18/llvm@18/18.1.8/bin/llvm-config
make
```

## Variants and versioning

```sh
make                 # build/debug/byepv-pxl-v$(VERSION).elf   (default)
make release         # build/release/...    no USB log file
make standalone      # build/standalone/... no USB, non-blocking stdout
make all-variants    # all three
make clean
make test            # python unit tests (tests/)
make deploy          # send the debug ELF to PS5_HOST:PS5_PORT
```

- `VERSION ?= 0.1.0` — bump it in the Makefile (or `make VERSION=x.y.z`);
  it is compiled into the payload banner and the artifact file names, and
  used for git tags / GitHub releases.
- `include/version.h` is generated by the Makefile (do not edit).
- `build/debug/byepv-pxl-latest.elf` is a symlink to the current debug
  build — the default for `scripts/ps5_run.py`.
- All variants are built with `-O0` (the resume hook uses noinline
  register saves and inline-asm single-steps; `-O0` is the validated
  configuration).

## Artifact naming

```
build/<variant>/byepv-pxl-v<VERSION>.elf     # versioned artifact
build/debug/byepv-pxl-latest.elf             # convenience symlink
```
